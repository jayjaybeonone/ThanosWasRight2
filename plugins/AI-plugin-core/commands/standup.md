description: "Turn recent activity into a crisp async standup: done / doing / blocked."
---

Write an async standup from the recent work (git log, open issues, this conversation).

Format:
- **Done** — shipped since last update.
- **Doing** — in flight today, with the expected outcome.
- **Blocked** — what's stuck and exactly what would unblock it (name the person/decision).

Three to five bullets per section, max. Plain language a non-engineer can follow.
