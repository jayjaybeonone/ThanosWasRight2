---
description: "Cleanly close out a work session: summarize, commit, and update project state."
---

Wrap up this work session. Produce, in order:

1. **What changed** — a tight bullet list of what was accomplished this session.
2. **State of the world** — what is now working, what is half-done, what is broken.
3. **Next step** — the single most valuable thing to do next session, phrased as an
   action someone could pick up cold.
4. **Open questions** — anything that needs a human decision.

Then:
- Update any project state/STATE.md/CONTEXT.md file that exists with the above.
- Stage and propose a commit with a clear message (do not push unless asked).

Keep it skimmable. This is a handoff, not an essay.
